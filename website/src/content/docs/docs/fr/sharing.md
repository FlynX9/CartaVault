## Principes d’accès

Les droits sont définis carte par carte. Posséder un compte ou être administrateur de l’instance ne suffit pas pour ouvrir une carte privée. Toutes les opérations sensibles sont contrôlées côté serveur, y compris lorsqu’une URL est saisie manuellement.

## Inviter un membre

1. Ouvrez **Cartes**.
2. Sur la carte concernée, choisissez **Membres**.
3. Saisissez l’adresse e-mail du destinataire.
4. Choisissez **Lecteur** ou **Éditeur**.
5. Envoyez l’invitation.

Un utilisateur existant reçoit une notification dans CartaVault et, si l’envoi d’e-mails est configuré, un message transactionnel. Un destinataire sans compte reçoit un lien lui permettant de créer son compte avant d’accepter l’accès.

## Répondre à une invitation

Les invitations en attente apparaissent dans le centre de notifications et dans le catalogue des cartes. Le destinataire peut accepter ou refuser. La carte n’est ajoutée à son espace qu’après acceptation.

## Modifier ou retirer un accès

Le propriétaire peut faire passer un membre de lecteur à éditeur, ou inversement, puis retirer son accès. Le retrait prend effet sur les requêtes suivantes ; il ne transfère ni ne supprime les données de la carte.

## Transférer la propriété

Le transfert est une proposition, jamais une mutation immédiate :

1. le propriétaire saisit l’adresse du futur propriétaire ;
2. CartaVault envoie une invitation de transfert ;
3. le destinataire accepte explicitement ;
4. la propriété change et l’ancien propriétaire conserve le rôle prévu par le serveur.

Si l’adresse n’a pas encore de compte, elle est invitée à s’inscrire puis à récupérer la propriété. Ne supprimez pas votre compte avant la validation du transfert.

## Annuler une invitation

Une invitation encore en attente peut être révoquée depuis la gestion des membres. Un lien révoqué, expiré ou déjà utilisé ne permet plus d’obtenir un accès.

## Bonnes pratiques

- accordez le rôle lecteur par défaut ;
- réservez le rôle éditeur aux personnes qui modifient réellement les données ;
- révisez les membres avant un export ou un transfert ;
- utilisez le transfert de propriété au lieu de partager les identifiants d’un compte ;
- retirez rapidement les accès devenus inutiles.
