## What are annotations for?

Annotations add geographic context to POIs: an area to explore, an access route, a parking area, a path, a boundary, or a temporary marker. They remain attached to the map and can be linked to a POI.

## Create an annotation

1. Open **Organization → Annotations**.
2. Choose a type and color, then give it a clear title.
3. Start drawing on the map: a shape is drawn by drag and drop, while a line is built from its points.
4. Cancel and redraw if needed, then validate to save it.

Drawing does not interrupt the POI record. Existing annotations can be displayed or hidden individually from the record’s **Plan / annotations** section.

## Icons and categories

Each annotation category can have a color and icon. The icon is reused in POI records and on the map, making annotations recognizable without adding noise to lists.

## Good practices

- Use short names such as *Secondary access*, *Parking*, or *Restricted area*.
- Prefer several simple annotations over one very dense shape.
- Hide irrelevant annotations before a screenshot, export, or trip-planning session.
