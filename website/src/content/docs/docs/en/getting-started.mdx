## Before you begin

You need the URL of a CartaVault instance and an active account. Depending on configuration, an administrator creates the account, a public registration is approved, or the account is created while accepting an invitation.

## Sign in

Open the instance URL, enter your email address and password, then select **Sign in**. *Remember me* extends the intended session lifetime on that device; do not use it on a shared computer.

An already authenticated session does not return to the sign-in form. CartaVault redirects it to the start screen selected in preferences.

## Understand the workspace

The top bar opens the dashboard, undo/redo actions, notifications, theme, and account. Main navigation exposes maps, places, trips, media, categories, tags, statuses, and trash as context allows.

On a map, Places and other panels can be collapsed or resized while the map remains the central navigation surface.

## Create your first map

1. From the dashboard, select **New map**.
2. Enter a name such as *France trip*.
3. Select the country.
4. Open the newly created map.

The country controls framing, coordinate checks, and the outside-country mask. A map owns its categories, statuses, places, trips, media, and members.

## Add your first place

Use the **+** button in Places, select a map-search result, or import KML/KMZ. For manual creation, provide at least a name and coordinates. Then add a category, status, visit duration, description, tags, links, and photos.

## Organize before scaling up

Define a small, consistent set of categories, statuses, and tags before a large import. Filters and dashboard analytics become useful immediately. **Imported** remains available for data that still needs classification.

## Configure the interface

Open <UiPath items={['Profile', 'Preferences']} /> to choose language, theme, density, basemap, time zone, startup screen, trash retention, and search and routing providers.
