## Prepare a map or trip

CartaVault supports **read-only offline use** after explicit preparation. In the **Maps** or **Trips** panel, use **Available offline**, choose the content, and download the package while connected.

The package includes places, detail cards, map organisation, and—when it is a trip—days, stops, nights, and routes that have already been calculated. Data remains tied to the account that downloaded it.

## What remains available

Without a connection, the installed app can start and display prepared maps or trips, related places, annotations, and stored route lines. An **Offline** indicator makes it clear that the data may be stale.

Edits, imports, photo uploads, route calculation, and synchronisation require a connection. CartaVault never queues an edit while claiming it was saved.

## Basemap and media

The basemap is not preloaded: tile-provider terms do not always allow bulk downloads. Markers and route lines remain usable on a neutral surface when no map background is available.

The package can retain optimised thumbnails for lists and detail cards. Originals and full galleries are not automatically downloaded to protect device storage.

## Update or delete

Open **My account → Offline data** to review used storage, update a package, or delete it. The keep-data action asks the browser for persistent storage, but device/browser behaviour is not guaranteed.

Signing out removes that account’s private offline data from the device. If sharing access is revoked, a package remains readable until the device reconnects; it is invalidated when CartaVault learns about the updated permission.
